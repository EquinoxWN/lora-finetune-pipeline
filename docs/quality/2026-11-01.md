# Quality check: 10 engineering rules (2026-11-01)

Scope: `src/lora_finetune_pipeline/` (pinned downloads, curation, prompts, metrics, cost, QLoRA
training, pipeline, CLI) and `tests/`. Windows 11, Python 3.14.5, CPU torch 2.14.1 in a fresh
`.venv` (deleted afterwards). The GPU comparison was not re-run: no change in this pass touches
training, evaluation or the reported numbers.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Every call can fail | fixed | Dataset downloads: 60 s timeout, size cap, SHA-256 check, HTTPS-only final URL (`data.py` `download`). Model snapshot: pinned revision, weights SHA-256 checked (`model.py` `fetch`; `huggingface_hub` applies its own HTTP timeouts). Two `except Exception` probes for the optional NVIDIA counter dropped the error: the NVML meter now keeps the reason in `_Nvml.unavailable`, and `versions()` records `nvidia_driver_error` next to `nvidia_driver: none`. Test `test_versions_say_why_no_gpu_driver_was_found`. |
| 2 | Writes safe to retry | fixed | Training checkpoints were already written to a temp file and renamed (`train.py` `_save`). The results JSON (`cli.py`) and `partial.json` (`pipeline.py`) were written in place, so a crash could leave half a file that a resumed run would then read; both now go through a temp file and `replace`. |
| 3 | No race conditions | fixed | Downloads used one shared `<name>.part`; two concurrent `prepare` runs could write the same file or rename it from under each other. Each call now uses its own `mkstemp` file, and a refused rename is accepted only if the target already has the pinned SHA-256. Test `test_concurrent_downloads_of_the_same_file_both_succeed` (10 rounds). |
| 4 | Don't trust the clock | pass | Durations use `time.perf_counter()` (`evaluate.py`, `gpu.py`, `train.py`); the one stored timestamp is UTC (`pipeline.py`: `dt.datetime.now(dt.UTC)`). |
| 5 | Read before changing | pass | Every cache variable set by `env.configure` is listed in `env.py` and exported in the `Makefile` (all point inside `.tmp`, test_env); the code reads no other environment variables. |
| 6 | Never break compatibility | pass | `nvidia_driver_error` is a new, optional field in the results JSON; nothing renamed or removed. |
| 7 | One source of truth | pass | Model, dataset and torch versions are pinned once (`config.py`, `Makefile`), and the README quotes the same values. |
| 8 | Small changes, no secrets, validate input | pass | No tokens or keys (downloads are anonymous). Configs, CSV rows, labels and CLI paths are validated with clear errors (`config.py`, `data.parse_csv`, `env.ensure_inside`). |
| 9 | Tests that can fail | fixed | No skips or tautologies. 15 hand mutants: 11 killed before, 15 after. |
| 10 | Re-verify | pass | Results below. |
